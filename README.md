# PeerDrop

P2P file sharing app - Open source, 50GB+, WebRTC, E2E encrypted.

## Features

- Share files up to 50GB directly between devices
- End-to-end encryption (DTLS 1.3)
- No file size limits
- No server storage
- QR code sharing
- Cross-platform (Web, Desktop, Mobile)

## Tech Stack

- **Frontend**: SvelteKit + TailwindCSS
- **Desktop**: Tauri 2.x
- **Mobile**: Capacitor
- **WebRTC**: simple-peer
- **Signaling**: Bun + Socket.io

## Quick Start

```bash
npm install
npm run dev
```
